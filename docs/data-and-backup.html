Data and backup

Everything lives in one data folder. Where that is depends on how you run Omnissiah:

  • Desktop app: your operating system's app data folder. macOS: ~/Library/Application Support/Omnissiah. Windows: %APPDATA%\Omnissiah.
  • Web version (Docker or Node): folders next to the project.

What is in it

Path in the data folder Contents
data/ the database (omnissiah.db) with all your conversations, projects, sources and settings, the memory mirror (memory.md), the folder snapshots (snapshots/) and the local embedding model that makes your documents searchable (models/)
skills/ your own skills, each as <name>/SKILL.md. Empty at the start; everything you save lands here
.env your keys and the session secret

The database is a single file and the rest is ordinary markdown. There is no export step: what you see on disk is your data. Original files you added as a source (PDFs and images) live inside the database as well, so they travel with that one file.

Making a backup

Copy the data folder while the app is not running. Restoring is putting the copy back. There is nothing more to it.

Do it with the app closed. A database still being written to while you copy it can leave you with a half-finished file.

Starting fresh

Close the app and delete the data folder. That wipes all your conversations, projects and settings; there is no undo. Make a copy first if you are in doubt.

The embedding model

When you add your first document as a source, Omnissiah downloads a local embedding model to data/models once. That is roughly 465 MB, so it takes a moment. After that it is cached, and it is immediately the largest part of your backup: much bigger than the database itself.

Everything stays on your own machine: no document text goes out to be made searchable.
