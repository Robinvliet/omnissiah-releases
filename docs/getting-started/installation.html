Getting started

Installation

Download the installer from the download page:

  • macOS (Apple Silicon): Omnissiah-<version>-arm64.dmg
  • Windows (64-bit): Omnissiah-Setup-<version>.exe

macOS

Open the .dmg and drag Omnissiah to Applications.

The app is deliberately not signed, so macOS blocks it the first time with a message saying it is damaged. It is not damaged. There are two ways to clear that, both once per version:

  • Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

  • Or open Terminal and paste:

    xattr -cr /Applications/Omnissiah.app

The first way is enough; the second is there for when the button does not appear.

Windows

Run the Setup.exe. SmartScreen shows "Windows protected your PC". Click More info and then Run anyway. This too is once per version, and the reason is the same: the installer is not signed.

There is no password

The desktop app skips the login screen. The built-in server listens on 127.0.0.1 only, the address of your own machine, so nobody on your network can reach it. Whoever is logged in on your computer can use the app, and they could already reach the data files anyway.

The web version does keep a password, because it can be reached by more devices through Tailscale. See Self-hosting.

Where your data ends up

Everything lives in your operating system's app data folder:

  • macOS: ~/Library/Application Support/Omnissiah
  • Windows: %APPDATA%\Omnissiah

That folder is completely separate from any Docker or development install. Making a backup is copying that folder; see Data and backup.
