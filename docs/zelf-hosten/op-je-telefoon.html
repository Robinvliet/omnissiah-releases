Zelf hosten

Op je telefoon

Deze route werkt via de webversie op je computer. De desktop-app draait op een wisselende interne poort en is nog niet via Tailscale te ontsluiten; mobiele toegang rechtstreeks vanuit de desktop-app staat op de wensenlijst.

Omnissiah is een PWA: je kunt hem op je telefoon "installeren" als app. Om er veilig bij te kunnen zonder iets op internet open te zetten gebruik je Tailscale, een privé-netwerk tussen alleen jouw eigen apparaten. De app blijft op localhost van je computer luisteren; Tailscale zet er een privé-HTTPS-adres voor.

Eenmalig instellen

  1. Installeer Tailscale op je computer, waar Omnissiah draait, én op je telefoon, en log op beide in met hetzelfde account: tailscale.com/download. Je apparaten zitten nu in hetzelfde privé-netwerk, je "tailnet".

  2. Start de webversie op je computer: docker compose up -d --build, of npm run start.

  3. Zet Tailscale ervoor op je computer, zodat het een privé-HTTPS-adres maakt dat naar je app doorverwijst:

    tailscale serve --bg 3000

    Gebruik je een andere APP_PORT, vul dan die poort in. Tailscale regelt automatisch een geldig TLS-certificaat. Met tailscale serve status zie je het adres, iets als https://<computernaam>.<tailnet>.ts.net.

tailscale serve houdt alles binnen je tailnet. Gebruik niet tailscale funnel: dat zet je app juist publiek op internet.

Openen en installeren op je telefoon

  1. Zorg dat Tailscale op je telefoon aan staat.
  2. Open het https://<computernaam>.<tailnet>.ts.net-adres in de browser.
  3. Log in met je wachtwoord.
  4. Installeer hem als app:
    • iPhone (Safari): deel-knop → Zet op beginscherm.
    • Android (Chrome): menu (⋮) → App installeren of Toevoegen aan startscherm.

Omnissiah staat nu als app-icoon op je telefoon en opent schermvullend. Hij werkt zolang je computer aanstaat, de webversie draait, en Tailscale op beide apparaten aan staat.
