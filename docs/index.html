What is Omnissiah

Omnissiah is an AI workspace that runs on your own computer. You talk to models from Google and Anthropic through your own API keys, to an endpoint you connect yourself (OpenRouter, Groq or your own gateway), or to models that live locally on your machine. There is no account, no subscription and no server owned by someone else: the app starts a server on your own machine that is only reachable there, and all your conversations live in a single file on your own disk.

What is in it

  • Conversations with multiple models side by side. There are no modes: what the assistant can do follows from the settings of that conversation, and deep research is something you start for one message.
  • Projects to group related conversations, with shared instructions and shared sources. A project can be set to Answer only from the sources, and then nothing outside them is fetched and nothing on your disk changes.
  • Sources per conversation or per project: documents, linked folders and attached files in one list, each showing roughly what it costs and when the model last used it. If everything fits in the context it goes along in full; otherwise the assistant searches it and points to the source with clickable citations.
  • Working in a folder with file tools and a terminal, behind a read-only switch and approval levels you set yourself.
  • Scheduled tasks that run on a schedule without you, in their own task conversation.
  • Memory, skills, personas and MCP servers to adapt the assistant to how you work.

Where to start

Download the installer from the download page and then work through Getting started: install, add a key or a local model, and have your first conversation.

If you would rather run Omnissiah as a web app instead of the desktop app, for example to use it on your phone too, that lives under Self-hosting.

What it is not

Omnissiah is for one person on one machine. There are no user accounts, no shared workspaces and no sync between devices. Email and calendar are deliberately not part of it.

The app does talk to the outside world, but only when you ask it to: to the model provider you added a key for, to the search engine when you turn on web search, and to the pages you have it fetch. What exactly happens there, and why the setup is safe, is on Privacy and security.
